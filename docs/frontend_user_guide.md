# 前端使用说明

这份说明只讲怎么使用，不要求理解前端代码。

## 1. 打开项目

先启动后端，再启动前端。浏览器访问：

```text
http://127.0.0.1:5173
```

## 2. 连接模型

1. 在“模型厂商”中选择你拥有 Key 的厂商。
2. 选择具体模型。
3. 粘贴 API Key。
4. 点击“测试并连接”。

“连接成功”后 Key 只留在这个页面的内存里。刷新、关闭页面或点击
“清除 Key”都会清除它；学习记录不会被清除。

## 3. 创建学习目标

必填：

- 目标名称；
- 你现在的背景；
- 想学习什么；
- 想达到什么程度。

可以选择“循序学习”“考试备考”，也可以写自己的 Prompt。创建后这些
内容不会修改，避免一条学习路径中途改变底层设定。填错时点击顶部
“＋ 新目标”重新创建。

一个项目可以拥有多个目标。顶部下拉框用于切换，目标之间互不影响。

## 4. 节点地图

- 每张卡片是一问一答。
- 主线默认从上往下。
- 分支会向左、向右或相对当前方向转弯。
- 红框卡片是下一次提问使用的当前位置。
- 小地图中的红色块与红框卡片同步。
- 拖动画布只改变视野，不改变当前位置。
- 单击卡片：右侧显示从根节点到它的用户提问历史。
- 双击卡片：把它切换为下一次提问的位置。
- 点击“查看完整对话”：查看没有截断的一问一答和参考来源。

根节点不能创建分支。一个节点的某个方向已经有连接时，不能重复占用。
所有允许方向用满后，分支按钮会禁用。

## 5. 继续提问与创建分支

默认直接输入并发送，会从当前分支末端继续。

需要单独追问时：

1. 双击要追问的非根节点；
2. 点击“从这里创建分支”；
3. 输入问题并发送。

如果双击的是已经有普通后继的旧节点，即使不手动开启按钮，界面也会
提示“下一条问答会转弯进入独立分支”，不会覆盖原路径。

资料范围可以选择：

- 自动：后端按模型能力使用公共知识库和厂商搜索；
- 仅公共知识库；
- 仅联网；
- 知识库 + 联网。

厂商本身不支持联网时，“仅联网”和“知识库 + 联网”会明确报错，
不会假装搜索过。

## 6. 历史与完整内容

右侧“追根溯源”默认只列用户问题，保持窗口简洁。点击“展开问答”后，
显示这条路径上的完整 AI 回答。

节点卡片有最低和最高尺寸。长内容会截断预览，但原文仍完整保存在本地，
点击“查看完整对话”即可查看。

## 7. 导入与导出

点击顶部“导出”，浏览器会下载一个 JSON 文件。文件包含：

- 学习目标；
- 全部节点和分支；
- 摘要；
- 引用来源；
- 当前分支位置。

文件不包含 API Key。

换设备后，打开同一应用，点击“导入”选择该 JSON 文件。导入完成后仍需
重新输入 API Key。

建议在重要学习阶段结束后导出一次。清理浏览器站点数据会删除尚未导出的
本地记录。
